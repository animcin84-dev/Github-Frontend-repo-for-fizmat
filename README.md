# Support Intelligence Frontend

Production-oriented frontend for an AI Support Intelligence Layer. The product is an overlay for existing support systems: evidence-first Copilot, deterministic policy boundaries, Shadow Mode, verified-resolution measurement, and support-to-product intelligence.

## Local development

```bash
npm install
npm run dev
```

Quality gate:

```bash
npm run lint
npm run typecheck
npm run build
```

The repository intentionally owns product workflows and visual language while using focused open-source dependencies for accessibility, URL state, virtualization, resizing, charts, and async state.
